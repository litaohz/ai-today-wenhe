# 批量插入图片

将 `archives-YYMMDD` 目录中的图片，按命名规则批量插入到对应的 `ai_posts_summary_YYYY-MM-DD.md` 文件中。

## 触发方式

用户 @此 skill，并指定目标目录（如 `@archives-260207`）。

## 支持的图片格式

支持所有 Markdown 兼容的常见图片格式：
- **PNG** (`.png`)
- **JPG/JPEG** (`.jpg`, `.jpeg`)
- **GIF** (`.gif`)
- **WebP** (`.webp`)

## 图片命名规则

| 命名格式 | 含义 | 示例 |
|---------|------|------|
| `N.<ext>` | 第 N 条重点帖子的唯一图片 | `3.png` → 第3条帖子 |
| `N-M.<ext>` | 第 N 条重点帖子的第 M 张图片 | `1-2.jpg` → 第1条帖子的第2张图片 |

> `<ext>` 可以是上述任意支持的图片格式扩展名

**排序规则**：
- 首位数字 → 决定插入到哪条重点帖子
- `-` 后的数字 → 同一帖子内多张图片的排列顺序（从小到大）

## 插入位置

图片插入到对应重点帖子的 **"链接"部分下方**、`---` 分隔线上方：

```markdown
**链接**：
- [链接1](url1)

![N-M](N-M.png)

---
```

## 执行步骤

1. **扫描目录**：列出目标目录中所有支持格式的图片文件（`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`）
2. **解析命名**：提取帖子序号和图片序号
3. **分组排序**：按首位数字分组，组内按序号升序
4. **批量插入**：修改 Markdown 文件，在对应位置插入图片引用

## 示例

**输入**：目录中有 `1-1.png`, `1-2.jpg`, `2.gif`, `3.webp`

**输出**：

| 帖子 | 插入图片 |
|-----|---------|
| 1 | `![1-1](1-1.png)` `![1-2](1-2.jpg)` |
| 2 | `![2](2.gif)` |
| 3 | `![3](3.webp)` |
