# 收集 Twitter/X AI 动态摘要

此技能旨在自动获取、过滤并总结精选 X (Twitter) 列表中的最新 AI 相关讨论。

## 背景
目标是生成一份来自硅谷和全球研究界的“高信噪比” AI 新闻日报，过滤掉噪音、政治话题和个人闲聊，专注于技术与行业动态。

## 输入
- **来源**: [Twitter List: 2010748418889752969](https://x.com/i/lists/2010748418889752969)
- **时间范围**: 2026-01-14 05:30 UTC 到 2026-01-15 05:30 UTC (或用户指定的其他范围)
- **主题**: 人工智能 (AI) 与 机器学习 (Machine Learning)

## 指令 (Instructions)

### 1. 浏览器导航 (Browser Navigation)
使用浏览器子代理 (Browser Sub-agent) 导航至 Twitter 列表页面：
`https://x.com/i/lists/2010748418889752969`

- 确保页面完全加载。
- 向下滚动足够的距离，以精准覆盖指定的时间段（例如 2026-01-14 05:30 UTC 到 2026-01-15 05:30 UTC）。
- 如果出现“显示更多” (Show more) 或类似按钮，请点击以加载更多历史内容。

### 2. 内容提取与过滤 (Content Extraction & Filtering)
提取时间线上的推文，并应用以下过滤规则。
**重要原则：宁可错杀不可放过 (Inclusion over Exclusion)**。只要推文内容与 AI 有一点关系，都应包含在内。仅剔除明显无关的内容。

- **时间过滤**:
  - 严格筛选出位于指定时间段内的推文 (例如 2026-01-14 05:30 UTC - 2026-01-15 05:30 UTC)。
  - 请仔细检查推文的时间戳。

- **主题过滤 (AI 相关)**:
  - **保留 (INCLUDE)**:
    - **任何**提及 AI, ML, LLM, 模型, 算法, 数据科学, 机器人, 自动化, 芯片(如NVIDIA) 的内容。
    - 哪怕只是简短的评论或转发，只要涉及 AI 话题，都保留。
    - 科技公司的动态（Google, Microsoft, OpenAI, xAI, Meta 等），只要不是纯粹的非技术行政公告（如“我们要搬家了”），通常都与 AI 战略有关，建议保留。
  - **排除 (EXCLUDE)**:
    - 明显与技术/AI 无关的政治话题（例如：特定选民统计、叛国罪指控、单纯的税收政策讨论）。
    - 纯粹的个人生活（如“我今天吃了好吃的”、“我要去度假”）。

### 3. 总结与格式化 (Summarization & Formatting)
将过滤后的内容总结为一份 Markdown 报告。**报告必须使用中文编写**。 需要有引用链接。
请参考 `examples` 目录下的 `ai_posts_summary_2026-01-14-with-ref.md` 文件作为风格参考。

#### 报告结构

1.  **标题**: 日期和标题 (例如：`# YYYY/MM/DD 硅谷AI圈动态`)
2.  **时间范围**: 收集数据的 UTC 时间范围。
3.  **总览表格**: 关键主题和事件的高层摘要表。
    ```markdown
    | 主题 | 关键事件 |
    |------|----------|
    | ...  | ...      |
    ```
4.  **详细部分**:
    对于每个重大更新，创建一个小节：
    ```markdown
    ### N. [公司/实体] - [标题/主题]

    **发布者**: [姓名/ID] ([最重要的职位/Title])
    *注意：务必注明作者 Title。如果作者有多个 Title，只保留最重要的一个。*
    **时间**: [UTC 时间]

    **核心内容**:
    - [要点 1]
    - [要点 2]
    ```
    *注意：如果多人讨论同一事件（例如 Google 发布新模型），请将相关推文合并到一个板块中。*

5.  **截图**: 如果捕获了特定截图，请将其放置在相关的小节中。

## 输出格式
最终产物应为一个 Markdown 文件，命名格式为 `ai_posts_summary_YYYY-MM-DD.md`。
确保所有生成的文本均为**中文**。
